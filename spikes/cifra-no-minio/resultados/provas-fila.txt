==================== Alternativa sem cópia: o arquivo aprovado ganha uma etiqueta no próprio bucket de envio ====================

# A credencial api-etiqueta só lê do bucket de envio o objeto com a etiqueta verificacao=aprovado.

$ cat ./config/politica-api-etiqueta.json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AssinaOEnvio",
      "Effect": "Allow",
      "Action": ["s3:PutObject"],
      "Resource": ["arn:aws:s3:::uniplus-envios/*"]
    },
    {
      "Sid": "AssinaALeituraSoDoArquivoAprovado",
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": ["arn:aws:s3:::uniplus-envios/*"],
      "Condition": {"StringEquals": {"s3:ExistingObjectTag/verificacao": "aprovado"}}
    }
  ]
}
